# Etiya SQL Training

This repository is a snapshot created for documentation and knowledge-sharing purposes, capturing the content of a technical training delivered for a specific audience. The training focused on SQL fundamentals and advanced query techniques.

## Main Covered Topics

- **SQL Fundamentals**: Basic `SELECT` statements, filtering with `WHERE`, and logical operators (`AND`, `OR`, `NOT`).
- **Advanced Filtering**: Using `IN`, `BETWEEN`, `LIKE`, and `IS NULL` for more complex data retrieval.
- **Data Aggregation**: `COUNT`, `GROUP BY`, and `HAVING` clauses to summarize and group data.
- **Sorting and Pagination**: Ordering results with `ORDER BY` and implementing pagination with `LIMIT` and `OFFSET`.
- **Joining Tables**: Combining data from multiple tables using `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, and `CROSS JOIN`.
- **Advanced Joins**: Using `SELF JOIN` for recursive relationships and combining multiple joins in a single query.
- **Subqueries**: Writing nested queries and correlated subqueries to handle complex filtering logic.
- **Common Table Expressions (CTEs)**: Using the `WITH` clause for creating temporary result sets, including recursive queries.
- **Practical Examples**: The `select.sql` file contains a series of queries demonstrating these concepts on the Northwind sample database.
